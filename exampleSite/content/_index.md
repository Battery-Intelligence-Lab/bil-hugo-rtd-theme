# BIL Hugo RTD Theme

Welcome to the example documentation site for the **BIL Hugo RTD Theme** — a modern Hugo theme inspired by Read the Docs, with Oxford blue styling designed for scientific documentation.

## Features

- Oxford blue sidebar with Lato/Roboto Slab typography
- Recursive section navigation with expand/collapse
- In-page table of contents
- Prev/next navigation
- Breadcrumbs
- Pagefind static search
- MathJax and Mermaid support
- Code copy buttons
- Admonition boxes (note, warning, tip, danger)
- Mobile-responsive hamburger menu
- Edit on GitHub links
- Zero jQuery — vanilla JS only
