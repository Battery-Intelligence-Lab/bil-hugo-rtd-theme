{{- $url := .Destination -}} {{- $isExternal := or (hasPrefix $url "http://") (hasPrefix $url "https://") (hasPrefix $url "//") -}} {{- /* Resolve .md links to Hugo page URLs */ -}} {{- if and (not $isExternal) (or (strings.HasSuffix $url ".md") (strings.Contains $url ".md#")) -}} {{- $fragment := "" -}} {{- $path := $url -}} {{- if strings.Contains $url "#" -}} {{- $parts := split $url "#" -}} {{- $path = index $parts 0 -}} {{- $fragment = printf "#%s" (index $parts 1) -}} {{- end -}} {{- with .Page.GetPage $path -}} {{- $url = printf "%s%s" .RelPermalink $fragment -}} {{- end -}} {{- end -}} {{ .Text | safeHTML }}
